<h1 align="center">ZenXPAM by Zenxsys</h1>

<p align="center"><strong>Every privileged action approved, enforced and provable.</strong></p>

ZenXPAM is an enterprise privileged access management (PAM) platform. It holds every privileged session to the scope an approver authorised, runs AI on local models inside your own deployment, governs non-human identities (service accounts, API keys, tokens, SSH keys and certificates), and produces signed evidence that an auditor can verify independently.

This organisation is home to the **developer tooling** for ZenXPAM: clients, a secrets-delivery CLI, infrastructure-as-code providers and an independent evidence verifier. The ZenXPAM platform itself is a commercial product and is **not** part of these repositories.

## What ZenXPAM does

- **Intent-locked access:** the written reason on an access request becomes an approver-reviewed command scope, enforced during the session.
- **Just-in-time and ephemeral access:** access and temporary accounts exist only for the approved task.
- **Agentless browser access:** RDP, SSH, VNC, web applications and Kubernetes consoles, with credentials injected at connect time.
- **Non-human identity governance:** inventory, safe rotation with a grace window and rollback, short-lived tokens, and secret delivery to applications.
- **Private AI:** local models inside your deployment, working with no outbound connectivity.
- **Evidence that proves itself:** hash-chained audit and signed evidence, verifiable offline.
- **Sealed vault backups and offline recovery**, and multi-tenant operation for managed service providers.
